# 开发

在总控已确认的授权范围内完成需求。项目根目录 AGENTS.md 定义共同授权、委派与完成规则；本 Skill 不要求另建任务或独立 Agent。

读取与目标相关的代码和调用链，明确当前行为与验收条件。优先复用现有架构，做满足需求的必要修改；避免无关框架、基础设施、依赖升级或目录重组。

- Bug：尝试复现、定位根因、修复并验证原问题，按影响范围回归。无法复现时记录已有证据与局限，不用吞错、绕过校验或硬编码掩盖原因。
- UI：检查交互、布局及相关状态；改变业务规则、API 含义或权限模型前，确认它是否属于当前需求。
- 功能或重构：检查调用方与边界条件。发现需要扩大技术栈、数据库或重要接口范围时，先完成独立的已授权工作，再明确必要取舍。

按改动风险选择验证。简单检查可以直接做；需要专门测试流程时读取 [testing](../testing/SKILL.md)。失败由本实现角色继续诊断修复，遵循总控的进展与预算规则。

交付修改位置、实际验证、风险和未验证事项；仅在委派交接时使用完整结果字段。
